# ParcelTrack

A modern, real-time parcel tracking and delivery management SaaS platform for logistics teams, delivery agents, and customers.

> 🚧 **Status:** In active development — Day 1 of 5

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS v4, MapLibre GL JS (OpenFreeMap / OpenStreetMap), Socket.IO Client
- **Backend:** Node.js, Express.js, Socket.IO, Zod, JWT, bcryptjs
- **Database:** PostgreSQL, Prisma ORM v6
